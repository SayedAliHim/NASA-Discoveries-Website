# <ins>NASA-Discoveries-Website</ins>
Ever wanted to go through the discoveries and inventions NASA made? Well, look no further for we've compiled all of them here in a fun and engaging way.
## Project Idea:
We compile and organize NASA's achievements in an engaging way that anyone can enjoy. We want it to capitalize on the intriguing details of NASA's discoveries in a way that people, outside the topics NASA circle around, want to learn more about it.
**Tools include** a simple website with flashy and interactive pages.

### Instructions:
Open the website at "www.thisisanexample.com". You will land in the home page. Explore the different pages by clicking on them. There will be interactive activities on each page, e.g a fun trivia quiz to test your knowledge on NASA facts.
